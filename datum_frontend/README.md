# Datum Frontend

Frontend-часть веб-платформы для внутреннего банка знаний компании.

---

## Стек

- React
- Vite
- Tailwind CSS
- React Router
- Axios
- OpenLayers

---

## Локальные установка и запуск

### 1. Перейти в папку `datum_frontend`
```bash
cd datum_frontend
```

### 2. Установить зависимости
```bash
npm install
```

### 3. Запустить проект
```bash
npm run dev
```

После запуска проект будет доступен по адресу:
http://localhost:5173/
