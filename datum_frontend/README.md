# Datum Frontend

Frontend-часть веб-платформы для внутреннего банка знаний компании.

## Стек

- React
- Vite
- Tailwind CSS
- React Router
- Axios
- OpenLayers

## Требования
- Node.js 20.19+ или 22+
- npm 10+

## Установка и запуск

### 1. Перейти в папку frontend
```bash
cd datum_frontend
```

### 2. Установить зависимости
```bash
npm install
```

### 3. Запустить проект
```bash
npm run dev
```

После запуска проект будет доступен по адресу:
http://localhost:5173/
